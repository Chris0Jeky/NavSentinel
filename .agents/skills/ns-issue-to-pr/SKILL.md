# NavSentinel Issue To PR

Orient with `AGENTS.md`, `autodoc/AGENT_INDEX.md`, and the relevant roadmap section. Pick one seam. Create a branch only when appropriate using `fix/`, `feat/`, `test/`, `infra/`, or `docs/`.

Implement one reviewable slice, verify narrowly, broaden when browser behavior changed, sync docs only when truth changed, and hand off summary, changed files, verification, residual risk, failures, docs sync, and next slice.
