## Design

Instrument only the controlled form fixture and test runner, not shipped guards. Capture submitted form/submitter identity and minimized effective-intent categories around input, mutation and operation; distinguish untrusted fixture reports from browser observations, product-reported decisions and independent receiver acceptance. Never record input values, bodies, full URLs or target tokens. A separate non-consuming receiver health probe brackets the observation. Every started run writes a terminal diagnostic, even on failure. Preserve rejected double spends and post-commit recovery as consequences, never convert them to prevention.

Keep the existing thirty-case assertion matrix and attack schedules unchanged. Record an opt-in detailed run and an uninstrumented control run in fresh profiles; preserve failures and retries (retries disabled for qualification). The existing matrix has paired attack arms and protected-only benign controls, not a matched four-arm campaign per variant. The consumer must not claim the stronger native Observatory four-arm certification.
