# AI-47 agent pass on the v0.5.0 release build (2026-09-26)

**Classification: automated agent evidence, not the owner Gate-3 result.** Every
AI-47 Human result in `ACTION_ITEMS.md` stays **OPEN — not run** unless Chris
records it or explicitly waives it.

Chris asked the agent to run as much of AI-47 as it could. This report is that
run.

## What was tested

- **Build:** tag `v0.5.0`, commit `15a81274b2b7db4d61a0be43a8f8149110add8e6`,
  checked out with LF endings. `npm run package:ext` on this checkout produced
  a zip byte-identical to the published release asset (SHA-256
  `b4c95c326ad9ce0d2ac07fa3129faaa174b6bc84eecd43cd2bb0c5c5c8cd8d7e`), so the
  `extension/dist` under test is the shipped artifact.
- **Browser:** Google Chrome 153.0.8010.53. Each spec used a fresh profile with
  realistic settings (`NAVSENTINEL_REALISTIC_CHROME=1`: back/forward cache and
  Chrome's popup blocker enabled). UI guard revision `b5238c36a8a9`.
- **Commands:** `npm run test:acceptance` with `NAVSENTINEL_LIVE=1`, then the
  live-web spec and the new row-8 spec again after a network outage.

## What automation cannot cover

- Chris's own daily Chrome profile, extensions and sign-ins. Chris loaded the
  v0.5.0 zip on 2026-09-26 and reported that it "works great so far". That is
  an owner observation, not an AI-47 row result.
- Subjective judgement: whether warnings read clearly, and whether the themes
  look right. Row 5 and AI-33 measure contrast and layout, not taste.
- Assistive technology such as a real screen reader. The specs drive keyboard
  paths only.
- Opening the popup from the toolbar icon. The specs open the popup page through
  the DevTools protocol.
- Sites outside the sampled live set.
