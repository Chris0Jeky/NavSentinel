Evasion 11: Shadow DOM overlay hiding

A benign-looking <div> host element covers the page, with a deceptive <a> link hidden inside its shadow root. elementsFromPoint() returns the host (a plain div), not the inner deceptive link.

The blank-anchor interception uses composedPath() which traverses into shadow DOM, so this specific attack is caught. But the CDS overlay scoring is completely evaded -- it only sees a benign div.
