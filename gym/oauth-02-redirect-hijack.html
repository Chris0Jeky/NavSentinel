OAuth 02: Redirect URI Hijack

MALICIOUS SCENARIO

This simulates an OAuth consent phishing attack where the redirect_uri points to an attacker-controlled domain instead of the legitimate application domain.

The user is tricked into initiating an OAuth flow from what looks like a real app, but the authorization code is sent to evil-collector.com. NavSentinel should flag this as an unexpected callback redirect (+30 NRS).
