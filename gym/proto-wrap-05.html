Proto Wrap 05

A strict-mode module wraps the enforcement methods NavSentinel patches (HTMLFormElement.prototype.submit, Location.prototype.assign, window.open) the way real form/analytics libraries do. If NavSentinel froze those slots non-writable, these assignments would throw TypeError: Cannot assign to read only property and abort init. Expected: all wraps succeed and the app renders. The Location check is initialization-only: Chromium's browser-owned window.location.assign method bypasses prototype dispatch; #458 tracks the actual interception boundary.
