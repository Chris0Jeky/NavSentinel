Chain 02: Simulated 3-Hop Redirect through URL Shortener

This scenario simulates a redirect chain: start → bit.ly → track.ads.com → landing.

In a real attack, the browser's webNavigation.onCommitted events would fire for each hop. This gym page simulates the chain by performing rapid same-tab redirects.

Expected:

  • After the chain completes, the NRS debug overlay should show nrs_redirect_chain_depth.
  • Known-redirector hops (bit.ly, track.ads.com) should trigger nrs_redirect_via_known_redirector.
  • Chain depth = 3, so depth penalty = +5 (one hop beyond threshold of 2).
  • 2 known redirector hops = +30 (capped).
