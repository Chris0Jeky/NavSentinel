Evasion 10: CSS transform: scale() overlay

The overlay is a 10x10px element scaled up by transform: scale(100), making it visually cover 1000x1000px. This tests whether CDS correctly uses the transformed bounding box (via getBoundingClientRect()) for coverage ratio calculation.

In Chrome, both elementsFromPoint() and getBoundingClientRect() account for CSS transforms, so this should NOT be a viable evasion. This fixture documents and verifies that behavior.
