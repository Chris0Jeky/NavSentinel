Evasion 07: pointer-events: none bypass

The visual overlay uses pointer-events: none so clicks pass through to the underlying elements. A document-level capturing click listener then opens a malicious URL via window.open.

CDS cannot see this overlay because elementsFromPoint() skips elements with pointer-events: none. The deceptive redirect relies on the main_guard.ts window.open intercept.
