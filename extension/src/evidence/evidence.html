EVIDENCE WITH BOUNDARIES

What this view can tell you

Recorded, not independently verified

Entries describe extension observations and decisions. Counts are not prevented attacks, protection rates or a safety verdict. An empty journal means no retained events.

Local and deliberately limited

This view reads the extension’s existing bounded history. It does not collect new page data, contact a server or connect to a desktop service. Missing fields stay unavailable.

You stay in control

Review navigation and credential settings, trust lists and retention in Protection settings. Clear behavioural data there to erase existing history through the shared reset flow.

Build and browser limits still apply

The standard build focuses on browser interactions. Broad JavaScript instrumentation is off. This journal cannot prove complete coverage of a page or that an observed consequence was prevented.
